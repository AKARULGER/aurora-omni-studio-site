Privacy Policy

Effective date: November 2, 2026 · AURORA OMNI STUDIO

What the software processes

AURORA OMNI STUDIO is a Windows desktop tool that stores project settings, creative text, generated media, video status and operational records on the user's own computer. Optional account connections may process TikTok or YouTube profile identifiers, publicly visible channel information, limited API responses, OAuth access and refresh tokens, and upload metadata needed for the features the user enables.

Why information is used

Information is used to enable authorized account connection, prepare user-requested videos, upload user-selected content where permitted, and retrieve relevant publication status. The app does not ask for your TikTok password; authorization occurs on official provider pages.

Where data is stored and shared

Project data is stored locally on the user's computer. Where available, OAuth tokens and other secrets are stored with the operating system's credential store. Data is transmitted to TikTok, Google or YouTube only when their official API functions are used. If the optional AI feature is configured, text prompts may be sent to that provider for generation. This static website does not contain a sign-in form or application credentials; its host GitHub may receive ordinary website access information under GitHub's own privacy practices.

Retention and deletion

Project files remain in the application's local workspace until removed by the user. Users can revoke access using the respective Google or TikTok connected-app settings and remove local project files and saved credentials from their own computer. Revoking access stops further permitted access even if local data has not yet been deleted. To ask about support or deletion options, use the support page without including personal or sensitive information.

Security and limits

Do not share passwords, email verification codes or OAuth secrets. External platform services have their own policies, permissions and availability limits. We do not sell personal data or place private account tokens on this site.

Changes

This document may be revised as the application changes. The date above will be updated with material policy changes.
